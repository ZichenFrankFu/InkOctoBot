# 中文名字常用字（given-name characters）— 用于「开篇章节 NLP 维度」更准的人名识别：
# 一个 2-3 字 token 若字字皆为名字常用字、且被 jieba 判为人名(nr/ns) 或为叠字名，
# 则判为人名片段剔除（避免 翠翠/晓东 这类给定名漏入高频词）。区别于「不是所有叠词
# 都是人名」：星星(n)/渐渐(d) 不会被误判，因为它们不被 jieba 标 nr 且非名字用字组合。
# 数据来源：github.com/callmefeifei/baby-names（男/女常用单字字典）。仅作检测辅助，
# 不在「资源管理」中 CRUD（与 translit_chars 同类）。
