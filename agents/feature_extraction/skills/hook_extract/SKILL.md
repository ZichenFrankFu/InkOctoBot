# 钩子识别

## 说明

特征提取技能之一。识别文本中用来「勾」住读者、驱动继续阅读的悬念 / 张力点，
标注其位置（章首 / 段中 / 章末）与内容。

## 输入

| Field | Type   | Required | Description    |
|-------|--------|----------|----------------|
| text  | string | yes      | 待分析的文本   |

## 输出

```json
{ "hooks": [ { "position": "章末", "content": "门外传来了不该出现的脚步声。" } ] }
```
